# 🩺 Skinfinity Derma — Admin Dashboard & RBAC Panel

This directory contains the luxury clinic Admin Dashboard built with **Bootstrap 5**, **Bootstrap Icons**, **SweetAlert2**, and vanilla JavaScript.

## ✨ Modules
- `index.html` — KPI Stat Cards & Clinic Operations Overview
- `appointments.html` — Appointments Management & Status Workflow
- `enquiries.html` — Leads Management (Franchise, EMI, Contact)
- `coupons.html` — Offers & Promo Code Generator
- `users.html` — Staff Accounts & RBAC Roles (Super Admin only)
- `treatments.html` — Treatments Catalog
- `doctors.html` — Doctors Management
- `banners.html` — Desktop & Mobile Responsive Hero Banners
- `before-after.html` — Photographic Results Management
- `reviews.html` — Google Verified Reviews Management
- `settings.html` — Clinic & SEO Settings
- `login.html` — Staff Login with Quick-Fill Role Pills
